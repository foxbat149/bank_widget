# Проект bank_widget

## Описание:

Проект bank_widget - это проект по управлению банковскими операциями

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:foxbat149/bank_widget.git
```
2. Установите зависимости:
```
poetry install --no-root
```
## Функционал:

1. Маскировка номеров карт и счетов.
2. Фильтрация операций по статусу.
3. Сортировка операций по дате.
